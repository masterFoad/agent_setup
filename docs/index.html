Claude Code Workshop

Welcome. Let's get your laptop ready.

Before the workshop, your computer needs a few free tools: the AI assistant you'll be working with, the editor you'll write in, and the pieces they run on.

Everything you need is on this page. Pick your computer, then work down: copy a command, paste it, press Enter. About 20 minutes, and you only do it once.

Pick your computer

How do you want to do this?

What you're installing

Everything you need, all free

  • Claude Codethe AI assistant you'll work with all day
  • Antigravity IDEthe app you'll write code in
  • Gitkeeps a history of your work, like unlimited undo
  • Node.jsruns JavaScript projects on your machine
  • Pythonruns the scripts Claude writes for you
  • gh, supabase, vercelcommand-line tools for GitHub, Supabase and Vercel

Homebrew comes along too — it's the helper that installs the rest. One command sets up everything.

Step 1

Install Claude Code

Copy this, paste it into Terminal, and press Enter. This is the only thing you install by hand.

Terminal
curl -fsSL https://claude.ai/install.sh | bash

When it finishes, close Terminal and open a new window.

Step 2

Log in

Terminal
claude

Your browser opens to log in. Use a Claude account on a paid plan — Pro or higher. You'll end up at a prompt waiting for you to type.

Step 3

Hand Claude the rest

Paste this line to Claude and press Enter:

Ask Claude
read https://masterfoad.github.io/agent_setup/lazy/mac.md and follow it exactly
Say yes once, and it stops asking Claude asks permission before it fetches that page and before it runs anything. Choose the option that says yes, and don't ask again — otherwise you'll be answering prompts the whole way through.
Step 4

Let it work

Claude installs Git, Node.js, Python and Antigravity IDE, checking each one as it goes. It takes a while, and it will tell you what it's doing. When it's finished you'll see:

ALL DONE:
git --version      2.51.0
node --version     v22.20.0
npm --version      10.9.3
python3 --version  Python 3.14.0
claude --version   2.1.4
gh --version       2.83.0
supabase --version 2.62.4
vercel --version   52.1.0
Antigravity IDE    installed

Still to do (these open a browser):
gh auth login
supabase login
vercel login

If something didn't work, Claude says NOT FINISHED instead and tells you which one and what to do. Quit Terminal and open a fresh window, then open Antigravity IDE from your Applications folder and sign in with your Google account.

Step 1

Run the setup

Copy this, paste it into Terminal, and press Enter.

Terminal
curl -fsSL https://raw.githubusercontent.com/masterFoad/agent_setup/v2.1.4/install-mac.sh -o /tmp/foad-install-mac.sh
/bin/bash /tmp/foad-install-mac.sh

It shows you what it's about to install and waits. Press Enter again to let it go, then leave it alone — it runs for a while, asks for your Mac password along the way, and finishes with a summary.

Don't add sudo Run it exactly as it is. The setup stops on purpose if you put sudo in front.

Every line should print a version number. If one doesn't, run the Step 1 command again — it picks up where it left off and skips whatever already worked.

Your browser opens to log in. Use a Claude account on a paid plan — Pro or higher.

Step 4

Open the editor

Open Antigravity IDE from your Applications folder and sign in with your Google account. That's everything — your laptop is ready.

Step 1

Run the setup

Copy this, paste it into PowerShell, and press Enter.

PowerShell
$path = Join-Path $env:TEMP "foad-install-windows.ps1"
Invoke-WebRequest "https://raw.githubusercontent.com/masterFoad/agent_setup/v2.1.4/install-windows.ps1" -OutFile $path
powershell -NoProfile -ExecutionPolicy Bypass -File $path

It shows you what it's about to install and waits. Press Enter again to let it go, then leave it alone — it runs for a while and finishes with a summary.

Two things while it runs Click Yes on any "allow this app to make changes?" box — it sometimes hides behind other windows. And the editor is a big download that can look frozen for several minutes; it isn't.

Only if the Step 1 command keeps failing. Install each tool yourself, one block at a time, so you can see which one is unhappy. Skip anything that already works, and say Yes to any permission box.

Check Windows' app installer

If this prints a version, carry on. If not, install App Installer from the Microsoft Store, then reopen PowerShell.

The big one — it can look frozen for minutes. The IDE at the end of the name matters. If it fails, download it from antigravity.google/download.

winget install --id Google.AntigravityIDE --exact --source winget --accept-package-agreements --accept-source-agreements

Try these in order, stop at the first that works. If none do, install from python.org and tick Add python.exe to PATH.

winget install --id Python.Python.3.14 --exact --source winget --accept-package-agreements --accept-source-agreements
winget install --id Python.Python.3.13 --exact --source winget --accept-package-agreements --accept-source-agreements

Claude Code

irm https://claude.ai/install.ps1 | iex

If that fails, try this instead:

winget install --id Anthropic.ClaudeCode --exact --source winget --accept-package-agreements --accept-source-agreements

Only if claude is still missing

This tells Windows where to find it, permanently. Then close PowerShell and open a new one.

$claudeDir = Join-Path $HOME ".local\bin"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*$claudeDir*") {
    [Environment]::SetEnvironmentVariable("Path", "$userPath;$claudeDir", "User")
}

scoop bucket add supabase https://github.com/supabase/scoop-bucket.git
scoop install supabase

$path = Join-Path $env:TEMP "foad-install-windows.ps1"
Invoke-WebRequest "https://raw.githubusercontent.com/masterFoad/agent_setup/v2.1.4/install-windows.ps1" -OutFile $path
powershell -NoProfile -ExecutionPolicy Bypass -File $path

سيعرض لك ما سيثبّته ثم ينتظر. اضغط Enter مرة أخرى للمتابعة، ثم اتركه يعمل — يستغرق وقتًا وينتهي بملخّص.

أمران أثناء التشغيل اضغط Yes على أي نافذة تسأل «هل تريد السماح لهذا التطبيق بإجراء تغييرات؟» — وقد تختبئ خلف النوافذ الأخرى، فتفقّد شريط المهام. كما أن المحرّر تنزيل كبير قد يبدو متجمّدًا لدقائق، وهو ليس كذلك.

الخطة البديلة: ثبّت أداة واحدة في كل مرة

استخدمها فقط إذا ظل أمر الخطوة ١ يفشل. ثبّت كل أداة بنفسك، كتلة واحدة في كل مرة، لتعرف أيّها تحديدًا يفشل. تجاوز أي أداة تعمل أصلًا، واضغط Yes على أي نافذة أذونات.

هذا يخبر ويندوز بمكانه بشكل دائم. ثم أغلق PowerShell وافتح نافذة جديدة.

$claudeDir = Join-Path $HOME ".local\bin"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*$claudeDir*") {
    [Environment]::SetEnvironmentVariable("Path", "$userPath;$claudeDir", "User")
}

آخر خطوة

سجّل الدخول إلى حساباتك

يثبّت الإعداد هذه الأدوات لكنه لا يستطيع تسجيل دخولك — كل واحدة منها تفتح المتصفح. نفّذها واحدة تلو الأخرى. وتحتاج حسابًا في كل خدمة أولًا، فأنشئها قبل الورشة إن لم تكن قد فعلت.

GitHub

اختر HTTPS ثم تسجيل الدخول عبر المتصفح عندما يسألك. هذا يتيح لك أيضًا رفع الشيفرة دون كتابة كلمة مرور في كل مرة.

gh auth login

تحقّق من نجاحها:

gh auth status

Supabase

supabase login

تحقّق من نجاحها:

supabase projects list

Vercel

vercel login

تحقّق من نجاحها — يجب أن تطبع اسم المستخدم:

vercel whoami
إذا فشلت إحداها تجاوزها وأكمل البقية. فهي مستقلة عن بعضها — فشل تسجيل الدخول إلى Vercel لا يؤثر على GitHub أو Supabase، ويمكنك العودة إليها لاحقًا.
