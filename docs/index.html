FOAD Dev Setup

A beginner-oriented environment setup for Windows and macOS: Git, Node.js, Python, Antigravity IDE, and Claude Code.

Version 2.1.3 Platforms Windows · macOS Duration 10–25 min

Abstract

This document describes the supervised installation procedure for the FOAD workshop development environment. The installer provisions Git, Node.js/npm, Python 3/pip, the Google Antigravity IDE, Claude Code, a starter Claude command and skill, and a plain-text terminal guide placed on the Desktop. Two installation paths are documented per platform: the pinned installer script (recommended) and a step-by-step manual fallback using only vendor-documented commands. Verification, troubleshooting, and distribution-integrity requirements are included.

§1

Before interns start

Confirm that each intern has:

  • 10–25 minutes, reliable internet, and several gigabytes of free disk space;
  • permission to install software — individual package installers may request administrator approval;
  • an eligible Claude subscription, Anthropic Console account, or supported provider — see Claude Code authentication and claude.ai plans;
  • a Google account, if the workshop requires Antigravity IDE sign-in.

The installers show this checklist and ask for confirmation before making changes. Existing starter files and the Desktop guide are preserved on reruns.

§2

Recommended distribution

For interns, use a versioned, signed release distributed by the instructor. Verify the published SHA-256 checksum before opening it.

  • Windows releases should be Authenticode signed.
  • macOS releases should be Developer ID signed and notarized.
  • Do not tell interns to bypass SmartScreen or Gatekeeper for an artifact they have not independently verified.
Notice The old v1.0.0 DMG does not contain the current installer and should not be distributed. Until signed v2.1.3 binaries are published, use the pinned source scripts in Part I / Part II below, only in a supervised setup session. The scripts pin FOAD's installer to the versioned v2.1.3 tag and download it before execution; published tags must never be moved. They still use official package managers and vendor installers, so review release notes before each workshop.

Instructors can compare the downloaded scripts against SHA256SUMS from the same tag before the session. Signed binary releases must publish checksums generated after signing/notarization.

Checksum — macOS
shasum -a 256 /tmp/foad-install-mac.sh
Checksum — Windows
Get-FileHash $env:TEMP\foad-install-windows.ps1 -Algorithm SHA256
§3

macOS — supervised installation

Requirements. macOS 14 (Sonoma) or newer — matching Homebrew's support tiers. Apple Silicon or Intel. Apple's built-in Terminal app (Applications → Utilities → Terminal).

3.1Run the pinned installer

Terminal
curl -fsSL https://raw.githubusercontent.com/masterFoad/agent_setup/v2.1.3/install-mac.sh -o /tmp/foad-install-mac.sh
/bin/bash /tmp/foad-install-mac.sh
Do not use sudo Never run these commands with sudo. Homebrew or individual package installers will request elevation only when needed. Do not pipe the script straight into bash — the installer refuses that path because Homebrew needs an interactive terminal.

3.2What the installer does

Table 1 · macOS installer steps, in order
#StepWhat happens
1Consent promptLists time, disk, admin, account and file-change expectations. Enter continues; q cancels.
2Check Mac & internetVerifies macOS (Darwin), refuses to run as sudo/root, requires macOS ≥ 14, confirms GitHub is reachable.
3Check HomebrewUses an existing brew, otherwise runs the official Homebrew installer. First install may ask for your Mac password and install the Xcode Command Line Tools.
4Save PATHAppends Homebrew and tool paths (~/.local/bin, ~/.claude/bin, ~/.claude/local) to ~/.zprofile / ~/.bash_profile.
5Update Homebrewbrew update. A failure here is a warning, not a stop.
6Install Gitbrew install git
7Install Node.js + npmbrew install node
8Install Python 3 + pipbrew install python
9Install Antigravity IDEbrew install --cask antigravity-ide. If the cask is unavailable, the download page opens in your browser.
10Install Claude CodeTries in order: native installer (curl -fsSL https://claude.ai/install.sh), then brew install --cask claude-code, then npm install -g @anthropic-ai/claude-code.
11Create starter filesWrites a starter skill to ~/.claude/skills/summarize-changes/ and a starter command to ~/.claude/commands/. Existing files are kept.
12Create Desktop guideWrites ~/Desktop/FOAD-terminal-basics.txt and opens it in TextEdit at the end.
13VerifyRuns --version for git, node, npm, python3, pip3, claude, then prints a ✔/⚠/✘ summary and next steps.
§4

macOS — worst case, by hand

If the installer stops partway and rerunning does not get past it, run these blocks in Terminal one at a time, in order, checking the result of each before moving on. Nothing here is FOAD-specific: every command is the vendor's own documented install. Skip any block whose tool already works.

4.1Homebrew — skip if brew --version already prints a version

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

4.2Put Homebrew on your PATH, then close and reopen Terminal

echo 'eval "$(/opt/homebrew/bin/brew shellenv)"' >> ~/.zprofile   # Apple Silicon
echo 'eval "$(/usr/local/bin/brew shellenv)"' >> ~/.zprofile      # Intel Macs
eval "$(brew shellenv)"

4.3Git

brew install git

4.4Node.js + npm

brew install node

4.5Python 3 + pip

brew install python

4.6Antigravity IDE — fallback: antigravity.google/download

brew install --cask antigravity-ide

4.7Claude Code — Anthropic's official installer

curl -fsSL https://claude.ai/install.sh -o /tmp/claude-install.sh
/bin/bash /tmp/claude-install.sh

If it fails, try brew install --cask claude-code, then npm install -g @anthropic-ai/claude-code.

4.8Add the Claude Code paths, then close and reopen Terminal

echo 'export PATH="$HOME/.local/bin:$HOME/.claude/bin:$HOME/.claude/local:$PATH"' >> ~/.zprofile

4.9Check everything — every line must print a version

git --version
node --version
npm --version
python3 --version
pip3 --version
claude --version
§5

macOS — troubleshooting

  • Copy the complete failing step and its preceding output for the instructor.
  • Password prompts display no characters while typing.
  • The full setup requires macOS 14 or newer to match Homebrew's supported baseline.
  • command not found: brew in a fresh Terminal → close and reopen Terminal once; the installer writes eval "$(brew shellenv)" into ~/.zprofile.
  • Never rerun with sudo; the installer stops if it detects root.
§3

Windows — supervised installation

Requirements. Windows 10 build 17763 (1809) or newer — the minimum for WinGet — and Windows PowerShell (Start → type PowerShell). Do not use a WSL/Ubuntu terminal; WSL is not required at any point in this workshop.

3.1Run the pinned installer

PowerShell
$path = Join-Path $env:TEMP "foad-install-windows.ps1"
Invoke-WebRequest "https://raw.githubusercontent.com/masterFoad/agent_setup/v2.1.3/install-windows.ps1" -OutFile $path
powershell -NoProfile -ExecutionPolicy Bypass -File $path

The installer verifies Claude using only the PATH that a genuinely new PowerShell will receive. If an older FOAD setup left claude.exe installed but unreachable, rerunning this version repairs the user PATH.

WSL is not required If Antigravity offers to install or open WSL, choose Skip, Cancel, or Not now. In Antigravity's terminal menu choose Select Default Profile → PowerShell, close the existing terminal, and open a new one.

3.2What the installer does

Table 2 · Windows installer steps, in order
#StepWhat happens
1Start the Desktop logTranscripts the whole run to Desktop\FOAD-setup-log.txt (OneDrive-redirected Desktops supported).
2Consent promptLists time, disk, UAC, account and file-change expectations, including the WSL note. Enter continues; Q cancels.
3Check your computerVerifies the Windows build (≥ 17763) and internet connectivity.
4Check WinGetUses WinGet if present; otherwise attempts registration / Microsoft Store recovery of App Installer, then winget source update.
5Install Gitwinget install --id Git.Git --source winget
6Install Node.js + npmwinget install --id OpenJS.NodeJS.LTS --source winget
7Install Antigravity IDEwinget install --id Google.AntigravityIDE. This is the big download and can look frozen — it is not. Fallback: the download page opens in your browser. Note: Google.Antigravity (without IDE) is a different app — an agent orchestrator with no editor. Do not install it instead.
8Install Python 3 + pipFirst available of Python.Python.3.14, 3.13, 3.12. Fallback: the Python for Windows page opens — tick "Add python.exe to PATH".
9Install Claude CodeRepairs an existing install first (PATH only), then the native installer (https://claude.ai/install.ps1, run in a separate PowerShell process), then the Anthropic.ClaudeCode WinGet package. Each path must produce a valid Anthropic Authenticode signature and a claude that resolves on the persistent user PATH, or it is treated as failed.
10Create workshop filesWrites a starter skill to %USERPROFILE%\.claude\skills\summarize-changes\ and a command to %USERPROFILE%\.claude\commands\, plus Desktop\FOAD-terminal-basics-v2.1.3.txt (opened in Notepad at the end).
11Final checkRe-resolves git, node, npm, python/py, pip, claude using only the persisted machine + user PATH — what a genuinely new PowerShell window will see — then prints a summary with a "how to fix" line per failed item.
  • Click Yes on any "Do you want to allow this app to make changes?" (UAC) prompt. It sometimes hides behind other windows — check the taskbar.
  • The final check deliberately ignores the current session's PATH, so a green summary means the tools really will work in a fresh window. Still open a new PowerShell afterwards.
  • The .claude directories, the versioned Desktop guide, and the setup log are the only files this script creates.
§4

Windows — worst case, by hand

If the installer stops partway and rerunning does not get past it, run these blocks in Windows PowerShell (not WSL) one at a time, in order, checking the result of each before moving on. Nothing here is FOAD-specific: every command is the vendor's own documented install. Skip any block whose tool already works. Answer Yes to any UAC prompt — it sometimes hides behind other windows.

4.1WinGet — skip if it already prints a version; otherwise install App Installer and reopen PowerShell

winget --version

4.2Git

winget install --id Git.Git --exact --source winget --accept-package-agreements --accept-source-agreements

4.3Node.js + npm

winget install --id OpenJS.NodeJS.LTS --exact --source winget --accept-package-agreements --accept-source-agreements

4.4Antigravity IDE — the big one; can look frozen for minutes. Note the IDE suffix.

winget install --id Google.AntigravityIDE --exact --source winget --accept-package-agreements --accept-source-agreements

Fallback: antigravity.google/download. Google.Antigravity (without IDE) is a different app.

4.5Python 3 + pip — try in order; stop at the first that succeeds

winget install --id Python.Python.3.14 --exact --source winget --accept-package-agreements --accept-source-agreements
winget install --id Python.Python.3.13 --exact --source winget --accept-package-agreements --accept-source-agreements
winget install --id Python.Python.3.12 --exact --source winget --accept-package-agreements --accept-source-agreements

Fallback: python.org/downloads/windows, ticking "Add python.exe to PATH".

4.6Claude Code — downloaded first, then run, so you can see what you are about to execute

$claudeInstaller = Join-Path $env:TEMP "claude-install.ps1"
Invoke-WebRequest "https://claude.ai/install.ps1" -OutFile $claudeInstaller -UseBasicParsing
powershell -NoProfile -ExecutionPolicy Bypass -File $claudeInstaller stable

If that fails, use the official WinGet package instead:

winget install --id Anthropic.ClaudeCode --exact --source winget --accept-package-agreements --accept-source-agreements

4.7Put Claude Code on your PATH permanently — only if step 4.9 says claude is missing

$claudeDir = Join-Path $HOME ".local\bin"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*$claudeDir*") {
    [Environment]::SetEnvironmentVariable("Path", "$userPath;$claudeDir", "User")
}

Adjust the folder if Claude installed elsewhere.

4.8Close PowerShell and open a new one

PATH changes do not reach the window that made them.

4.9Check everything — every line must print a version

git --version
node --version
npm --version
python --version
pip --version
claude --version

4.10Confirm a genuinely new shell can see Claude

This is the check the installer performs, and the one that catches a PATH that was never persisted.

$machinePath = [Environment]::GetEnvironmentVariable("Path", "Machine")
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
$env:Path = "$machinePath;$userPath"
claude --version
§5

Windows — troubleshooting

  • Send FOAD-setup-log.txt from the Desktop to the instructor.
  • If claude is missing in a normal PowerShell, rerun the current setup; it repairs and verifies the persistent user PATH. If it still fails, send FOAD-setup-log.txt to the instructor.
  • If claude is missing only inside Antigravity, cancel any WSL prompt, choose Select Default Profile → PowerShell, close the existing terminal, and create a new terminal. WSL is not required.
  • Large WinGet downloads can appear idle; check for a hidden UAC prompt in the taskbar.
  • If winget is not recognised, install App Installer from the Microsoft Store and rerun.
  • If python opens the Microsoft Store instead of running, reinstall Python with "Add python.exe to PATH" ticked, or use py --version.
  • A "no valid Anthropic signature" warning means the Claude binary on disk is not the official signed one — do not work around it; rerun setup and report it.
  • The WinGet registration / Store recovery path needs validation on a clean Windows VM before each workshop.
§6

After installation

  1. Close and reopen PowerShell or Terminal.
  2. Run claude and follow the login instructions (or type /login). Claude Code requires a paid Claude plan (Pro or higher), an Anthropic Console account, or a supported provider — see authentication.
  3. Open Google Antigravity IDE (Start Menu on Windows, Applications on macOS) and sign in with a Google account. On Windows, open Antigravity IDE, not the separate app called just "Antigravity".
  4. Read the FOAD terminal guide on the Desktop (FOAD-terminal-basics-v<version>.txt on Windows, FOAD-terminal-basics.txt on macOS).
Verify
git --version
node --version
npm --version
python --version     # Windows
python3 --version    # macOS
claude --version

If setup is incomplete, follow the final summary and rerun it. Existing workshop files are preserved, but the setup is not a general-purpose rollback or uninstaller for third-party packages.

§7

Release artifacts & maintainer policy

Building releases. See packaging/README.md. Release builders require a clean working tree, HEAD tagged exactly as v$(cat VERSION), and matching script/package versions. Builders emit a .sha256 file beside each artifact. FOAD_ALLOW_UNTAGGED_BUILD=1 is available only for local test builds.

Maintainer policy.

  • Never move a published version tag or replace an existing release asset.
  • Record the source commit and checksums in release notes.
  • Test Windows with a standard user plus separate administrator credentials.
  • Test macOS on both Apple Silicon and Intel where supported.
  • Run the validation workflow — including tests/test_release_contract.py and the Windows PATH check in tests/test_windows_path.ps1 — and verify failure/recovery paths before distribution.

FOAD Dev Setup

إعداد بيئة تطوير موجَّه للمبتدئين على ويندوز وماك: Git وNode.js وPython وAntigravity IDE وClaude Code.

الإصدار 2.1.3 الأنظمة ويندوز · ماك المدة 10–25 دقيقة

الملخّص

تصف هذه الوثيقة إجراء التثبيت الخاضع للإشراف لبيئة تطوير ورشة FOAD. يوفّر المثبّت Git وNode.js/npm وPython 3/pip وبيئة Google Antigravity IDE وClaude Code، إضافةً إلى أمر ومهارة تمهيدية لـ Claude ودليل نصي لسطر الأوامر يوضع على سطح المكتب. توثَّق طريقتان للتثبيت لكل نظام: سكربت المثبّت المثبَّت على إصدار محدد (الموصى به)، ومسار يدوي احتياطي خطوة بخطوة يستخدم أوامر المورّدين الموثّقة فقط. تشمل الوثيقة التحقق واستكشاف الأخطاء ومتطلبات سلامة التوزيع.

§1

قبل أن يبدأ المتدربون

تأكد أن لدى كل متدرب:

  • من 10 إلى 25 دقيقة، واتصال إنترنت موثوق، وعدة غيغابايتات من المساحة الفارغة؛
  • صلاحية تثبيت البرامج — قد تطلب بعض المثبّتات موافقة المسؤول؛
  • اشتراك Claude مؤهّل أو حساب Anthropic Console أو مزوّد مدعوم — انظر مصادقة Claude Code وخطط claude.ai؛
  • حساب Google إذا كانت الورشة تتطلب تسجيل الدخول إلى Antigravity IDE.

تعرض المثبّتات هذه القائمة وتطلب التأكيد قبل إجراء أي تغيير. تُحفَظ الملفات التمهيدية الموجودة ودليل سطح المكتب عند إعادة التشغيل.

§2

التوزيع الموصى به

للمتدربين، استخدم إصدارًا موقَّعًا ومرقَّمًا يوزّعه المدرّب. تحقق من بصمة SHA-256 المنشورة قبل فتحه.

  • إصدارات ويندوز يجب أن تكون موقَّعة بتوقيع Authenticode.
  • إصدارات ماك يجب أن تكون موقَّعة بمعرّف مطوّر Apple وموثَّقة (notarized).
  • لا تطلب من المتدربين تجاوز SmartScreen أو Gatekeeper لملف لم يتحققوا منه بأنفسهم.
تنبيه ملف DMG القديم v1.0.0 لا يحتوي على المثبّت الحالي ويجب عدم توزيعه. إلى حين نشر ثنائيات v2.1.3 موقَّعة، استخدم سكربتات المصدر المثبَّتة في الجزء الأول / الجزء الثاني أدناه، وفي جلسة إعداد خاضعة للإشراف فقط. تثبّت السكربتات مثبّت FOAD على الوسم المرقّم v2.1.3 وتنزّله قبل تنفيذه؛ ويُمنع نقل الوسوم المنشورة. تستخدم السكربتات مديري الحزم الرسميين ومثبّتات المورّدين الرسمية، فراجع ملاحظات الإصدار قبل كل ورشة.

يمكن للمدرّبين مقارنة السكربتات المنزَّلة مع SHA256SUMS من الوسم نفسه قبل الجلسة. يجب أن تنشر الإصدارات الثنائية الموقَّعة بصماتٍ مولَّدة بعد التوقيع/التوثيق.

البصمة — ماك
shasum -a 256 /tmp/foad-install-mac.sh
البصمة — ويندوز
Get-FileHash $env:TEMP\foad-install-windows.ps1 -Algorithm SHA256

ماك — استكشاف الأخطاء

  • انسخ الخطوة الفاشلة كاملة مع المخرجات التي سبقتها وأرسلها إلى المدرّب.
  • حقول كلمة المرور لا تعرض أي حروف أثناء الكتابة.
  • يتطلب الإعداد الكامل macOS 14 أو أحدث بما يوافق الحد الأدنى المدعوم في Homebrew.
  • ظهور command not found: brew في Terminal جديد ← أغلق Terminal وأعد فتحه مرة واحدة؛ يكتب المثبّت eval "$(brew shellenv)" في ~/.zprofile.
  • لا تُعد التشغيل بـ sudo أبدًا؛ يتوقف المثبّت إذا اكتشف صلاحيات root.
§3

ويندوز — التثبيت الخاضع للإشراف

المتطلبات. ويندوز 10 بناء 17763 (الإصدار 1809) أو أحدث — الحد الأدنى لـ WinGet — وWindows PowerShell (ابدأ ← اكتب PowerShell). لا تستخدم طرفية WSL/أوبونتو؛ لا حاجة إلى WSL في أي مرحلة من هذه الورشة.

3.1شغّل المثبّت المثبَّت على الإصدار

PowerShell
$path = Join-Path $env:TEMP "foad-install-windows.ps1"
Invoke-WebRequest "https://raw.githubusercontent.com/masterFoad/agent_setup/v2.1.3/install-windows.ps1" -OutFile $path
powershell -NoProfile -ExecutionPolicy Bypass -File $path

يتحقق المثبّت من Claude باستخدام PATH الذي ستراه نافذة PowerShell جديدة فعلًا فقط. إذا ترك إعداد FOAD قديم claude.exe مثبّتًا لكن غير قابل للوصول، فإن إعادة تشغيل هذا الإصدار تُصلح PATH الخاص بالمستخدم.

لا حاجة إلى WSL إذا عرض Antigravity تثبيت WSL أو فتحه، فاختر Skip أو Cancel أو Not now. في قائمة الطرفية داخل Antigravity اختر Select Default Profile ← PowerShell، وأغلق الطرفية الحالية وافتح واحدة جديدة.

3.2ماذا يفعل المثبّت

الجدول 2 · خطوات مثبّت ويندوز بالترتيب
#الخطوةما يحدث
1بدء سجل سطح المكتبيسجّل التشغيل كاملًا في Desktop\FOAD-setup-log.txt (يدعم سطح مكتب محوَّلًا إلى OneDrive).
2الموافقة الأوليةيعرض توقعات الوقت والمساحة وUAC والحساب وتغييرات الملفات، بما فيها ملاحظة WSL. اضغط Enter للمتابعة أو Q للإلغاء.
3فحص الجهازيتحقق من بناء ويندوز (≥ 17763) والاتصال بالإنترنت.
4فحص WinGetيستخدم WinGet إن وُجد؛ وإلا يحاول التسجيل / الاسترداد من متجر مايكروسوفت لتطبيق App Installer، ثم winget source update.
5تثبيت Gitwinget install --id Git.Git --source winget
6تثبيت Node.js + npmwinget install --id OpenJS.NodeJS.LTS --source winget
7تثبيت Antigravity IDEwinget install --id Google.AntigravityIDE. هذا هو التنزيل الكبير وقد يبدو متجمدًا — لكنه ليس كذلك. الاحتياطي: تُفتح صفحة التنزيل في المتصفح. ملاحظة: Google.Antigravity (بدون IDE) تطبيق مختلف — منسّق وكلاء بلا محرر. لا تثبّته بدلًا منه.

9تثبيت Claude Codeيُصلح تثبيتًا موجودًا أولًا (PATH فقط)، ثم المثبّت الأصلي (https://claude.ai/install.ps1 في عملية PowerShell منفصلة)، ثم حزمة Anthropic.ClaudeCode عبر WinGet. يجب أن يُنتج كل مسار توقيع Authenticode صالحًا من Anthropic وأمر claude يظهر على PATH الدائم للمستخدم، وإلا اعتُبر فاشلًا.
10إنشاء ملفات الورشةيكتب مهارة تمهيدية في %USERPROFILE%\.claude\skills\summarize-changes\ وأمرًا في %USERPROFILE%\.claude\commands\، إضافة إلى Desktop\FOAD-terminal-basics-v2.1.3.txt (يُفتح في Notepad في النهاية).
11الفحص النهائييعيد التحقق من git وnode وnpm وpython/py وpip وclaude باستخدام PATH المحفوظ للجهاز والمستخدم فقط — أي ما ستراه نافذة PowerShell جديدة فعلًا — ثم يطبع ملخصًا مع سطر «كيف تُصلح» لكل عنصر فاشل.
  • اضغط Yes على أي نافذة UAC «هل تريد السماح لهذا التطبيق بإجراء تغييرات؟». قد تختبئ خلف نوافذ أخرى — راقب شريط المهام.
  • يتجاهل الفحص النهائي عمدًا PATH الخاص بالجلسة الحالية، لذا فإن الملخص الأخضر يعني أن الأدوات ستعمل فعلًا في نافذة جديدة. افتح مع ذلك نافذة PowerShell جديدة بعد الانتهاء.
  • مجلدات .claude ودليل سطح المكتب المرقّم وسجل الإعداد هي الملفات الوحيدة التي ينشئها هذا السكربت.
§4

ويندوز — الحالة الأسوأ: التثبيت يدويًا

إذا توقف المثبّت في منتصف الطريق ولم تُجدِ إعادة التشغيل، نفّذ هذه المقاطع في Windows PowerShell (وليس WSL) واحدًا تلو الآخر وبالترتيب، وتحقق من نتيجة كل مقطع قبل الانتقال إلى التالي. لا شيء هنا خاص بـ FOAD: كل أمر هو التثبيت الموثَّق من المورّد نفسه. تجاوز أي مقطع تعمل أداته بالفعل. أجب Yes على أي نافذة UAC — قد تختبئ خلف نوافذ أخرى.

4.1WinGet — تجاوزه إذا كان يطبع رقم إصدار؛ وإلا ثبّت App Installer وأعد فتح PowerShell

winget --version

4.2Git

winget install --id Git.Git --exact --source winget --accept-package-agreements --accept-source-agreements

4.3Node.js + npm

winget install --id OpenJS.NodeJS.LTS --exact --source winget --accept-package-agreements --accept-source-agreements

4.4Antigravity IDE — التنزيل الكبير؛ قد يبدو متجمدًا لعدة دقائق. لاحظ اللاحقة IDE.

winget install --id Google.AntigravityIDE --exact --source winget --accept-package-agreements --accept-source-agreements

الاحتياطي: antigravity.google/download. تذكّر أن Google.Antigravity (بدون IDE) تطبيق مختلف.

4.5Python 3 + pip — جرّبها بالترتيب وتوقف عند أول أمر ينجح

winget install --id Python.Python.3.14 --exact --source winget --accept-package-agreements --accept-source-agreements
winget install --id Python.Python.3.13 --exact --source winget --accept-package-agreements --accept-source-agreements
winget install --id Python.Python.3.12 --exact --source winget --accept-package-agreements --accept-source-agreements

الاحتياطي: python.org/downloads/windows، مع تفعيل "Add python.exe to PATH".

4.6Claude Code — يُنزَّل أولًا ثم يُشغَّل، لترى ما ستنفّذه

$claudeInstaller = Join-Path $env:TEMP "claude-install.ps1"
Invoke-WebRequest "https://claude.ai/install.ps1" -OutFile $claudeInstaller -UseBasicParsing
powershell -NoProfile -ExecutionPolicy Bypass -File $claudeInstaller stable

إذا فشل، استخدم حزمة WinGet الرسمية بدلًا منه:

winget install --id Anthropic.ClaudeCode --exact --source winget --accept-package-agreements --accept-source-agreements

4.7أضف Claude Code إلى PATH بشكل دائم — فقط إذا قالت الخطوة 4.9 إن claude مفقود

$claudeDir = Join-Path $HOME ".local\bin"
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
if ($userPath -notlike "*$claudeDir*") {
    [Environment]::SetEnvironmentVariable("Path", "$userPath;$claudeDir", "User")
}

عدّل المجلد إذا ثُبّت Claude في مكان آخر.

تغييرات PATH لا تصل إلى النافذة التي أجرتها.

$machinePath = [Environment]::GetEnvironmentVariable("Path", "Machine")
$userPath = [Environment]::GetEnvironmentVariable("Path", "User")
$env:Path = "$machinePath;$userPath"

§5

ويندوز — استكشاف الأخطاء

  • أرسل FOAD-setup-log.txt من سطح المكتب إلى المدرّب.
  • إذا كان claude مفقودًا في نافذة PowerShell عادية، أعد تشغيل الإعداد الحالي؛ فهو يُصلح PATH الدائم للمستخدم ويتحقق منه. إذا استمر الفشل، أرسل FOAD-setup-log.txt إلى المدرّب.
  • إذا كان claude مفقودًا داخل Antigravity فقط، ألغِ أي نافذة WSL، واختر Select Default Profile ← PowerShell، وأغلق الطرفية الحالية وأنشئ واحدة جديدة. لا حاجة إلى WSL.
  • تنزيلات WinGet الكبيرة قد تبدو متوقفة؛ ابحث عن نافذة UAC مخفية في شريط المهام.
  • إذا لم يُتعرَّف على winget، ثبّت App Installer من متجر مايكروسوفت وأعد التشغيل.
  • إذا كان python يفتح متجر مايكروسوفت بدل التشغيل، أعد تثبيت Python مع تفعيل "Add python.exe to PATH"، أو استخدم py --version.
  • تحذير «لا يوجد توقيع Anthropic صالح» يعني أن ملف Claude على القرص ليس النسخة الرسمية الموقَّعة — لا تلتف عليه؛ أعد تشغيل الإعداد وأبلغ عن المشكلة.
  • مسار تسجيل WinGet / الاسترداد من المتجر يحتاج تحققًا على جهاز ويندوز افتراضي نظيف قبل كل ورشة.
§6

بعد التثبيت

  1. أغلق PowerShell أو Terminal وأعد فتحه.
  2. شغّل claude واتبع تعليمات تسجيل الدخول (أو اكتب /login). يتطلب Claude Code خطة Claude مدفوعة (Pro فأعلى) أو حساب Anthropic Console أو مزوّدًا مدعومًا — انظر المصادقة.
  3. افتح Google Antigravity IDE (قائمة ابدأ في ويندوز، Applications في ماك) وسجّل الدخول بحساب Google. في ويندوز، افتح Antigravity IDE وليس التطبيق المنفصل المسمى «Antigravity» فقط.
  4. اقرأ دليل FOAD لسطر الأوامر على سطح المكتب (FOAD-terminal-basics-v<version>.txt في ويندوز، FOAD-terminal-basics.txt في ماك).
التحقق
git --version
node --version
npm --version
python --version     # Windows
python3 --version    # macOS
claude --version

إذا كان الإعداد ناقصًا، اتبع الملخص النهائي وأعد التشغيل. تُحفَظ ملفات الورشة الموجودة، لكن الإعداد ليس أداة عامة للتراجع أو لإزالة حزم الطرف الثالث.

§7

حزم الإصدار وسياسة الصيانة

بناء الإصدارات. انظر packaging/README.md. يتطلب بناء الإصدار شجرة عمل نظيفة، ووسم HEAD مطابقًا تمامًا لـ v$(cat VERSION)، وتطابق إصدارات السكربتات والحزم. يُنتج الباني ملف .sha256 بجانب كل حزمة. المتغير FOAD_ALLOW_UNTAGGED_BUILD=1 متاح للبناءات الاختبارية المحلية فقط.

سياسة الصيانة.

  • لا تنقل وسم إصدار منشورًا ولا تستبدل ملف إصدار موجودًا أبدًا.
  • سجّل نسخة المصدر (commit) والبصمات في ملاحظات الإصدار.
  • اختبر ويندوز بمستخدم عادي مع بيانات اعتماد مسؤول منفصلة.
  • اختبر ماك على معالجات Apple Silicon وIntel حيثما كان مدعومًا.
  • شغّل سير التحقق — بما فيه tests/test_release_contract.py وفحص PATH لويندوز في tests/test_windows_path.ps1 — وتحقق من مسارات الفشل والاسترداد قبل التوزيع.
